# Changelog

## 1.0.0 - 2024-01-01

- Initial release
- Generate Eloquent models from database tables
- Generate migrations from database schema
- Generate seeders from table data
- Support MySQL, PostgreSQL, SQLite, SQL Server
- Support PHP 7.2.5+ and Laravel 7–8
- Commands: `generate:from-database`, `generate:model`, `generate:migration`, `generate:seeder`
